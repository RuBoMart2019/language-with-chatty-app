# Language with Chatty

Independent language learning website with guest practice and private learner accounts. No ChatGPT account is required.

Signed-in learners can upload chapter images or PDFs, review extracted content, generate short practice lessons, and save their private chapter. Each reading request supports up to eight selected pages. AI content requires review before use.

Learning progress, textbook files, and chapter drafts have owner-only access. API credentials are held only in server secrets. Natural Korean and American English voices are available for signed-in learners.
